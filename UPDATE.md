# How to install

1. Create (or open) your profile repo: `adarshbhagatjii/adarshbhagatjii` (must be public).
2. Upload `README.md` and the `assets/` folder to its root, replacing the old README.
3. Fonts are embedded inside the SVGs, so nothing else is needed. Font licenses are in `licenses/`.

To change text (name, roles, skills), edit the SVG files directly, or bump `?v=1` to `?v=2` in the README after replacing an SVG so GitHub refreshes its image cache.
