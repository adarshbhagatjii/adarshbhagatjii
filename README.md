# 🚀 Generative AI Engineer Journey

A hands-on journey into **Generative AI**, focusing on **NLP, LLMs, LangChain, and LangGraph**.

---

## 📌 Overview
- Foundations: AI, ML, Deep Learning, Neural Networks  
- NLP Pipeline: Tokenization, Preprocessing, Normalization, Vectorization, Word Embeddings  
- Large Language Models (LLMs): Transformer-based, context understanding, text generation  
- Prompt Engineering: Zero-shot, One-shot, Few-shot prompting  
- LangChain: Models, Prompt Templates, Output Parsers, Chains, Memory, Agents  
- RAG (Retrieval-Augmented Generation): Vector DBs, Embeddings, Retriever, Context-aware generation  
- LangGraph: Stateful workflows, multi-step reasoning, conditional branching  

---

## 💻 Tech Stack
- Python 🐍  
- NLTK, SpaCy, Scikit-learn  
- LangChain, LangGraph  
- Vector Databases (FAISS, Chroma)  

---

## 📊 Key Learnings
- Complete NLP pipeline understanding  
- How LLMs process & generate language  
- Prompt engineering for structured outputs  
- RAG systems for real-world applications  
- Building stateful AI workflows with LangChain & LangGraph
